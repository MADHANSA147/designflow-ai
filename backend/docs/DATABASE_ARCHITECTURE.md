# DesignFlow AI - Database Architecture

The backend utilizes PostgreSQL managed via Prisma ORM. The relational model is structured around a central `Project` entity that tracks every aspect of the AI-driven design process.

## 1. Authentication & Tenancy
- **User, Account, RefreshToken:** Standard NextAuth/OAuth compatible authentication entities.
- **Workspace & WorkspaceMember:** Organizations can have multiple users with RBAC (Role-Based Access Control).
- **Project:** Belongs to a Workspace and acts as the root container for a design artifact.

## 2. Product Planning (The "Idea")
- **ProductBrief:** Stores target audience, core problem, and tone.
- **Persona & Feature:** Tied directly to the ProductBrief to contextualize the product.

## 3. UX Planning
- **UXPlan:** The overarching user experience strategy.
- **UserFlow:** High-level journeys inside the UX plan.
- **UserFlowNode & UserFlowEdge:** A directed graph architecture to map out user decision trees and screen transitions.

## 4. UI & Design System
- **DesignSystem:** Project-wide tokens.
- **ColorToken, TypographyToken, SpacingToken:** Immutable atomic design tokens generated by AI or set by the user.
- **Component & ComponentVariant:** Reusable UI elements defined by base styles and prop-driven variants (stored as JSON structures).

## 5. Screen Data Model
- **Screen:** A structured view representation. Instead of images, it stores:
  - `layout`: JSON representation of constraints (Flexbox/Grid).
  - `componentTree`: The DOM-like tree of instances.
  - `styles`, `responsiveBehavior`, `interactions`: Component-level bindings.
- **ScreenComponent:** Overrides and specific instance properties for global components used on a screen.

## 6. Prototyping
- **Prototype:** Wrapper for interactive flows.
- **PrototypeConnection:** Links a `sourceScreen` to a `targetScreen`, bound by a specific trigger (e.g., `CLICK`) on a `triggerNodeId`, including animations.

## 7. AI & Memory
- **DesignMemory:** Persistent, long-term context (brand rules, preferences, AI decisions) ensuring the AI remains contextually aware across sessions.
- **AIConversation, AIMessage, AIGeneration:** Chat histories and the tangible artifacts (JSON payloads) produced during conversations.
- **AIReview & AccessibilityReview:** Automated auditing logic measuring UX health and WCAG compliance.

## 8. Versioning & Assets
- **ProjectVersion:** Immutable JSON snapshots of the entire project state allowing time-travel functionality.
- **GeneratedCode:** Artifacts exported for React, Vue, or HTML.
- **Asset:** Metadata for binary files (images, icons, fonts) stored externally in S3.
- **ExportJob:** Async tracking for heavy export processes.
